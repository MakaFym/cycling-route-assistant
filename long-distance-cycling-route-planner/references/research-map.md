# 外部算路受阻时的真实输入研究预览

此路径不是完整地图的替代品。用途是用同一套 Skill 模板检验真实 GPX、接入候选、原路线首尾缺口、手机和桌面布局；最终导航里程仍须独立取得。

本路径要求原始 OSM、已定位起点和明确拓扑/方向。只有 GPX 或未定位起点名称时，不在这里补造道路候选；使用 [GPX-only 参考预览](gpx-only-preview.md)，其产物没有道路图层、接驳候选或总里程。

```sh
node scripts/prepare-research-map.mjs --gpx INPUT.gpx --osm RAW_OSM.json --start LAT,LON --start-crs wgs84 --topology loop --direction forward --days 1 --title "实际起点一日路线研究预览" --out-dir PRIVATE_TEST_DIR
```

输入为原始 GPX、本地原始 OSM 数据、坐标系明确的实际起点及用户指定的拓扑/方向。`--topology loop|open` 和 `--direction forward|reverse` 必填；不能从端点接近推断闭环。指定独立终点时传 `--end LAT,LON --end-crs wgs84|gcj02`，可用 `--start-name/--end-name` 设置当前地点名称。未指定终点时，loop 返回实际起点，open 结束在指定方向的原路书尾点；一天为默认。未知或重复选项会报错，不得静默忽略用户目标。

未核实的入口与道路侧别保持候选，不从旧地图或聊天记录复制已完成方案。闭环从抽样和起终点附近原顶点比较实际去程与返程道路代价，旋转主段但完整保留原段；不是全局最优接入证明。非闭环保留指定方向完整主段，去程接到主段头，必要离开道路接到实际终点，不擅自省略原段以求最短。用户要求裁切或重规划时另作明确计划，不能用该研究路径代替。道路投影与实际坐标之间的缺口单列，不画直线补齐；候选尚未考虑所有现状、入口和方向，不是最终路线。

输出固定为 `draft`，导航段与已核实关键点为空，总里程为空，所有候选距离不作为骑行里程显示。首尾没有连通道路候选时，不画直线闭环；定位计算也不能隐式连线。完整原GPX按原顺序作为独立参考层，旋转/切分研究主段不替代原图；道路候选不能标为高德方案。无服务证据时，两视口还须检查这两个来源边界。

研究预览打包本地 OSM 道路背景和 Leaflet，不发起在线底图请求。这不是完整离线导航地图：不含完整地点检索与详细 POI，OSM 当前通行情况未核实。在线成品仍要另测详细底图缩放和高德导航。

实际用浏览器打开生成的 `research-map.html`，至少测试 390×844 和 1440×1000。记录完整路线是否被面板遮挡、是否有横向溢出、草稿按钮是否禁用、缩放与点选是否工作，以及跨段空白处不会被当成路线。保存截图和可重复运行的测试，不只看生成命令退出码。

测试环境已有 Playwright 时可运行 `node scripts/check-map-browser.mjs research-map.html PRIVATE_QA_DIR`。可用环境变量 `PLAYWRIGHT_MODULE` 指定测试环境中已安装的模块路径，`MAP_TEST_CHROME` 指定本机 Chrome；Skill 本身不打包浏览器或另行安装系统组件。该脚本在断网环境保存手机、桌面截图，并实测路线适配、草稿禁用、缩放、定位拒绝、无隐式跨段线和分段里程进度。它不能证明在线底图或真实手机 App 调起成功。

不得把“研究图已成功渲染”“合成测试通过”“能打开高德链接”或“网页文档声明有骑行功能”写成真实路线已导航验收。逐项记录外部算路、道路核对、端点删除、手机 App 调起与在线底图的状态。只有实际证据齐备才提升为完整地图。
